# WARP⚡FALL SMP Wiki

Official player wiki for Warpfall SMP.

This repository is designed to be published with GitHub Pages. The site is a single responsive page containing the player guide, gameplay, economy, commands, ranks, compatibility, voice chat information, rules, FAQ and community link.

## Current server guide

The wiki intentionally does not document fishing or leaderboard features because those are currently not part of the active player guide.

## Publishing

Enable GitHub Pages for this repository and select the main branch as the deployment source. GitHub Pages will then publish the site from `index.html`.
